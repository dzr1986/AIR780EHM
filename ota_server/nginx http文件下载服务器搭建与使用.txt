//Nginx搭建文件下载服务器
1、安装nginx
sudo apt update
sudo apt install nginx
2、配置 Nginx
Nginx 的配置文件通常位于 /etc/nginx/nginx.conf 或 /etc/nginx/conf.d/default.conf。你可以编辑这个文件来配置文件下载服务器
假设你想将 /var/www/fileserver 目录下的文件提供下载，可以添加或修改如下配置：
mkdir -p /var/www/fileserver
vim /etc/nginx/nginx.conf
server {
    listen 8008;
    server_name 114.132.241.236;

    location /downloads {
        alias /var/www/fileserver;
        autoindex on;  # 启用目录列表
        autoindex_exact_size off;  # 显示文件大小（KB/MB）
        autoindex_localtime on;  # 使用本地时间显示文件修改时间

        # 如果需要限制下载速度，可以取消注释以下行
        # limit_rate 100k;  # 限制下载速度为 100KB/s

        # 如果需要限制并发连接数，可以取消注释以下行
        # limit_conn addr 10;  # 每个 IP 最多 10 个并发连接
    }
}
放在http {}块内部
配置说明：
listen 8008;：监听 8008 端口。
server_name your_domain_or_ip;：替换为你的域名或 IP 地址。
location /downloads：定义 URL 路径 /downloads，用户可以通过 http://114.132.241.236:8008/downloads 访问文件。
alias /var/www/fileserver;：指定文件存储的目录。
autoindex on;：启用目录列表，用户可以看到目录中的文件列表。
autoindex_exact_size off;：以更友好的方式显示文件大小（如 KB、MB）。
autoindex_localtime on;：使用本地时间显示文件的修改时间。
3、创建文件目录
确保 /var/www/fileserver 目录存在，并且 Nginx 有权限读取该目录：
sudo mkdir -p /var/www/fileserver
sudo chown -R www-data:www-data /var/www/fileserver  # Ubuntu/Debian
sudo chown -R nginx:nginx /var/www/fileserver        # CentOS/RHEL
4、测试配置并重启 Nginx
sudo nginx -t
如果测试通过，重启 Nginx 以应用配置：
sudo systemctl restart nginx
5、访问文件下载服务器
浏览器访问：http://your_domain_or_ip/downloads
wget http://your_domain_or_ip/downloads/yourfile.zip
6、 （可选）配置 HTTPS

//测试
cd /var/www/fileserver/
echo "test" > 1.txt
wget http://114.132.241.236:8008/downloads/1.txt

//要让Nginx更好地作为文件下载服务器，可以添加以下配置：
server {
    listen 80;
    server_name download.example.com;
    
    location /downloads/ {
        alias /path/to/your/files/;
        
        # 启用自动索引（可选）
        autoindex on;
        
        # 优化下载性能
        sendfile on;
        tcp_nopush on;
        tcp_nodelay on;
        
        # 设置合适的缓冲区大小
        output_buffers 1 512k;
        
        # 限制下载速度（可选）
        # limit_rate 1m;
        
        # 设置文件下载的Content-Disposition
        if ($request_filename ~* ^.*?\.(txt|pdf|doc|docx|xls|xlsx|ppt|pptx|zip|rar|gz|tar|exe|mp3|mp4|avi)$) {
            add_header Content-Disposition 'attachment';
        }
    }
}

注意事项
带宽限制：大量并发下载可能会耗尽服务器带宽，可以使用limit_rate指令限制单个连接的下载速度。
系统限制：确保系统打开文件描述符限制足够高（ulimit -n）。
磁盘I/O：对于非常高的并发量，需要考虑磁盘I/O性能，SSD比HDD更适合高并发下载场景。
内存使用：大文件下载时，确保服务器有足够的内存处理并发请求。
总之，Nginx非常适合作为文件下载服务器，能够高效地处理多个客户端同时下载同一个文件的需求。
