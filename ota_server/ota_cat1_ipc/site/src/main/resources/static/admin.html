下发升级

      

        
先在「我的固件」上传差分包，并勾选升级全部或指定 IMEI。再填写设备 IMEI 与目标版本，通过 MQTT 通知模组来本服务器拉包。

        
点「下发 OTA」后下方黑框必须出现 JSON。"status": "PUBLISHED" 表示 2004 已发出。设备已经是该版本时会提示无需下发，不会再发 MQTT。
