# 日常只用这个目录里的三个界面

双击即可：

| 文件 | 做什么 |
|------|--------|
| **01_流程检测.bat** | 人形 / UART / MQTT / 信号强度检测 |
| **02_Cat1烧录.bat** | 烧 Cat.1 脚本（对齐 Luatools「下载脚本」） |
| **03_MQTT测试.bat** | 协议客户端：下发 200x、看 100x |

源码分别在：

- `flow_monitor/` 流程检测
- `flash/` Cat.1 烧录
- `mqtt/` MQTT 测试

其它命令行工具在 `../t31x/`（推 T31 ipc）和 `../debug/`（一次性脚本），平时不用进。
